## 01-presentacion.txt
Bienvenido a tu jueza de IA para Pura Raza Española.

En este vídeo veras cómo un usuario usa la plataforma de principio a fin. Actualmente es una demostración pensada para beta testers:

Primero entramos con una cuenta de cliente.

Una vez dentro, estamos ya en un entorno privado donde solo tu veras tus caballos.

Todo está pensado para que el usuario sepa en cada momento dónde está y qué puede hacer, pero os guiaremos por todo el proceso.

---

## 02-crear-ficha.txt
Crear Ficha de caballos:
A continuación creamos la ficha de un ejemplar. En este caso usamos los datos de "Destacado Nadales II". Rellenamos los campos principales: nombre, sexo, capa, fecha de nacimiento, registro si lo tenemos, microchip, ganadería y una breve descripción. También subimos una imagen de referencia del caballo. Esta imagen se guarda en la ficha y sirve como referencia visual para futuras evaluaciones.

---

## 03-evaluacion.txt
Evaluación de un caballo:
Una vez creada la ficha, vamos directamente a evaluar ese ejemplar. JudgePREAI ya trae precargado el caballo seleccionado. Podemos confirmar la imagen de referencia o subir otra foto. En este caso usamos la que ya teníamos. Pulsamos "Evaluar" y el sistema lanza el análisis.

En pocos segundos aparece el resultado. Vemos la puntuación global, un resumen visual y la ficha ANCCE adaptada a foto fija.

Las regiones de movimiento aparecen como "no evaluado", lo cual es correcto porque estamos usando solo una imagen. El resto de la morfología sí se valora y queda reflejado de forma clara y profesional.

---

## 04-descargar-informe.txt
Desde esta misma pantalla podemos descargar el informe en PDF. Este documento es el que el usuario puede guardar, imprimir o compartir.

Tiene la misma estructura que una evaluación oficial de la ANCCE y está pensado para que sea fácil de leer tanto para el usuario como para terceros.

---

## 05-historial.txt
Historial:
Además del PDF, el usuario puede volver a la ficha del caballo o consultar su historial.

En el historial se ven todas las evaluaciones realizadas, con la fecha, el nombre del ejemplar y un acceso rápido al detalle y al informe. Esto permite llevar un seguimiento ordenado de cada animal a lo largo del tiempo.

---

## 06-cuenta.txt
Tu cuenta:
También puedes editar opciones de tu cuenta, como la contraseña o los avisos que quieras recibir y para respetar tu privacidad puedes solicitar la eliminación de toda tu información cuando sea necesario.

## 07-cierre.txt
